Robot Summer: Autonomous Rescue Robot

Summer 2025

ENPH 253's scenario was a burning pet shelter: two minutes to find stuffed-animal "pets" in a hazard-filled course and bring them to safety. Our team built a fully autonomous robot with custom ESP32 PCBs, PID motor control and state-machine navigation.

ESP32 · KiCad · C++ · Onshape · Laser cutting · Waterjet

Read more

Mechanical

We started with quick shape prototypes cut on the laser cutter to get a feel for the robot's form, then used the same process for the final chassis and extended it to waterjet-cut parts.

Electrical

The electronics were a crash course in real-world debugging: parasitic capacitance, noise coupling through ground planes, and the moment you realize the lumped circuit model really is just a model. I designed boards in KiCad with separated analog and digital paths and debugged them with a scope and wavegen.

Software

Firmware was written in object-oriented C++, with each component wrapped behind a clean interface so higher-level navigation logic could treat hardware as a black box. PID gains were tuned wirelessly over WiFi.

16-bit RISC CPU

Sep 2024 — Jan 2025

A custom RISC processor in Verilog with ARM-inspired instruction decoding and memory-mapped I/O, verified with self-checking testbenches and deployed to a DE1-SoC FPGA.

Verilog · Quartus · ModelSim · FPGA

Read more

A state-machine controller interprets the instruction decoder's output and drives control signals for the ALU and memory through fetch, decode, execute, memory and writeback.

The instruction set covers arithmetic (ADD, SUB), logic (AND, MVN, CMP), data movement (MOV), memory access (LDR, STR) and branches (B, BEQ, BNE, BLT, BLE). Load/store support made it possible to run small programs and watch the CPU's behaviour directly on the board.

The top-level design ties the decoder, ALU and memory into a single datapath. The project left me keen to go further into branch prediction, superscalar designs and vector processors like GPUs.
